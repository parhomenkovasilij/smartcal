# SmartCal

Розумний календар-планувальник з автоматичним розподілом навантаження.
Програма знаходить вільні проміжки у розкладі, розбиває великі завдання на
робочі блоки до дедлайну та перераховує графік, якщо блок пропущено.

## Запуск

```
python main.py
```

Потрібен Python 3.10+ (Tkinter і SQLite входять до стандартної бібліотеки).

## Тести

```
python -m unittest -v
```

## Структура

| Модуль | Призначення |
|---|---|
| `smartcal/models.py` | Класи предметної області: FixedEvent, Task, Block, Settings |
| `smartcal/validation.py` | Перевірка введених даних |
| `smartcal/scheduler.py` | Аналітичне ядро: пошук вікон, розбиття, перепланування |
| `smartcal/storage.py` | Збереження у локальну БД SQLite |
| `smartcal/service.py` | Сервісний шар між інтерфейсом і ядром |
| `smartcal/export.py` | Зведена таблиця розкладу, експорт у CSV/TXT |
| `smartcal/gui.py` | Графічний інтерфейс (Tkinter) |
